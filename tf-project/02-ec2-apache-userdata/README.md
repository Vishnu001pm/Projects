# Automated Apache Web Server Deployment on AWS EC2

## Project Overview

Automated the provisioning of an AWS EC2 instance and Apache web server using Terraform and Bash User Data.

## Technologies Used

* AWS EC2
* Terraform
* Ubuntu 24.04
* Bash Scripting
* Apache2

## Project Files

* `main.tf` – Terraform configuration for EC2 provisioning.
* `install-apache2.sh` – Bash script for Apache installation and website deployment.

## Deployment Result

The EC2 instance was successfully provisioned, Apache installed automatically, and a static HTML website deployed using Terraform User Data.
